Entraîneur « Ricochay »

Poursuite bimanuelle à deux manivelles — entraînement type épreuve psychomotrice (APC mk2 en USB / Web MIDI)

MIDI : initialisation…

Principe de l'épreuve : un point cible (rouge) se déplace automatiquement le long de la trajectoire. Avec les deux manivelles (boutons rotatifs de l'APC : X horizontal, Y vertical), gardez votre point (vert) sur la cible le plus longtemps possible. Le score est le pourcentage du temps sur la cible, converti en classe 1–9. Niveau 3 = essai de 2 minutes, comme l'épreuve standard. Sans APC : flèches du clavier / WASD, ou souris directement sur le plateau.

Apprentissage des manivelles

Cliquez sur un bouton puis tournez le bouton rotatif concerné sur l'APC : le premier message CC reçu lui est assigné. « Auto » assigne X puis Y aux deux premiers boutons tournés.
